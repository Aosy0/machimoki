# machimoki デモビデオ ストーリーボード v2

WISS / PLATEAU AWARD 提出用デモビデオ（任意提出）。Remotion で制作する。
**v2 でデザイン方向を全面改訂**（v1 の「AI生成プロモ」的な記号を排除）。

---

## 0. v2 の目的（最重要）

v1 は「AIが作ったプロモ動画」の典型記号にほぼ全項目該当していた。
v2 では**構成と尺は維持**しつつ、以下を全廃する。

- グラデーション文字 / ネオン配色 / 放射グロー / box-shadow の光
- 丸ピル型チップ（STEPバッジ等）/ カード型UI / 巨大数字カード / `✓ OK` / 回転スタンプ
- スローガン調コピー（「そのまま」「選んで、出力するだけ。」「合格したモデルだけ…」等）
- 全要素のスタッガー・スライドイン、全静止画の Ken Burns、パルスするハイライト
- 全中央揃え、em ダッシュ `—`、`×` 記号

**避けるべきAI生成の3典型**（`frontend-design` スキルより）:
(1) クリーム紙面＋明朝＋テラコッタ / (2) 黒背景＋蛍光1色 / (3) 細罫線のブロードシート風。
v2 はいずれにも寄せない。**太めの構造線（2px）＋実データ＋実寸の寸法線**で構成する。

## 2. デザイン方向：製作仕様書（fabrication spec sheet）

主題は「都市の3Dデータを物理的な印刷物に変換するツール」。その世界の語彙
（経度緯度・縮尺・mm・寸法線・LOD・水密・シェル・タイル・スライサー）から視覚言語を作る。
論文調（明朝・紙面）にはしない。**エンジニアの仕様書／工程図**のトーン。

### カラートークン

| 役割 | 値 | 用途 |
|---|---|---|
| `ground` | `#eef1f4` | 画面地。冷たい薄灰 |
| `plate` | `#ffffff` | アプリ素材を貼る図版の下地 |
| `ink` | `#101418` | 本文・見出し |
| `muted` | `#5b6672` | 補助文字・単位 |
| `rule` | `#ccd4dc` | 罫線（構造線は 2px、区切りは 1px） |
| `accent` | `#1f5f8b` | 沈んだ測量青。注目箇所・選択状態 |
| `fail` | `#9c3b30` | 検証の fail / 課題の欠損 |
| `pass` | `#2c6e49` | 検証の pass |

- グラデーション・グロー・影は使用禁止。色面はベタ塗りのみ
- 角丸は最大 4px（図版プレートのみ）。ピル形状は禁止

### タイポグラフィ

| 役割 | フォント | 使い方 |
|---|---|---|
| 見出し | NotoSansJP 700 | 字間 -0.01em。最大 64px |
| 本文 | NotoSansJP 400 / 500 | 30〜40px |
| データ・寸法・座標・検証値・CLI | **等幅フォント**（新規同梱） | 数値の桁を揃える。26〜34px |

- weight 900 の多用をやめる（見出し 700、強調 500 まで）
- 見出しは**左揃え**。中央揃えは使わない
- 文字サイズは v1 より一段小さい（v1 の 88〜200px → 最大 64px）

### レイアウト原則

- 12カラム相当のグリッド。本文は左揃え
- アプリ素材は `plate`（白地・1px rule 枠・角丸4px・影なし）に載せて「図版」として扱う
- **番号（01 / 02 / 03）は実在する工程順なので使用可**。ただしチップ形状は使わず素のテキスト
- 実データを載せる「タイトルブロック」（選択範囲・設定値・検証値）を置く。**装飾ではなく情報**

## 3. シグネチャ（唯一の大胆な要素）

**白模型ターンテーブルに、実寸の寸法線を重ねる。**

```
      ←──────── 122 mm ────────→
   ┌───────────────────────────┐  ↑
   │                           │
   │   ［ 白模型ターンテーブル ］   │ 150 mm
   │                           │  ↓
   └───────────────────────────┘
```

- デジタルの都市モデルが「物理的なモノ」であることを一目で伝える、この題材固有の表現
- **数値は実測のみ**。`captures/preview-kitasenju.png` / `preview-shinjuku-white.png` に
  アプリが表示している W/D（mm）を読み取って使用する
- 判読できない場合は**数値を出さずスケールバーのみ**（左右に目盛り、単位なしの相対バー）
- それ以外の要素はすべて静かに保つ

## 4. タイムラインと確定コピー

コピーは下記が最終。`—`・`×`・感嘆形・「そのまま」の重複は使用禁止。

### Scene 1 — タイトル（f0–120 / 4s）
- ワードマーク: `machimoki`（単色 ink。グラデーション禁止）
- 一文: `PLATEAUの3D都市モデルと地形から、3Dプリント可能な水密メッシュ（3MF / STL）を生成するツール`

- 見出し（左）: `配信データは、水密ではない`

  1. `建物メッシュは閉じた立体ではない（底面が開いている）`

  赤字は欠損面の破線と注記のみ。**記号を丸で囲むアイコンは廃止**

### Scene 3 — 解決（f300–390 / 3s）

## 5. モーション原則

- 1シーンにつき**意図的な出現は1〜2回**。全要素を律儀にスタッガーさせない
- フェードは 8〜12F。`translateY/X` によるスライドインは原則使わない（罫線の描画とフェードのみ）
- **Ken Burns は廃止**（静止画は静止させる）
- ハイライトは**細い静止アウトライン**（グロー・パルスなし）。UIの注目箇所にのみ使用
- クリップ（mp4）はそのまま再生する（これが「動き」の主役）
- ワイプは Scene 3→4 の1回のみ

## 7. 実装メモ

- 変更対象は `video/src/**` のみ。素材（`public/captures/**`）は**再キャプチャせずそのまま使う**
- コンポジション契約（ID / 1920x1080 / 30fps / 1800F）とシーン境界は変更禁止
- 等幅フォントを1つ `video/public/fonts/` に同梱し `fonts.ts` に登録する（OFL ライセンスのもの）
- `ui.tsx` の共通部品は v2 のトークンに合わせて作り直す（`Logo` / `Kicker` / `StepChip` /
  `CaptionBar` / `HudChip` / `HighlightRing` / `AssetMissing`）
- 決定論的アニメーション（`spring` / `interpolate` のみ、`Math.random()` 禁止）

## 8. 検証

1. `npx remotion still` で各シーンの代表フレームをレンダリング（`--concurrency=2`）
2. 検証観点（**AI臭チェックリスト**）:
   - グラデーション文字 / ネオン色 / グロー / 影 がない
   - 丸ピル・カード・スタンプ・`✓ OK` がない
   - スローガン調の文言がない（事実文のみ）
   - 全要素がスタッガーで動いていない / Ken Burns がない
   - 中央揃えの多用がない
   - クリーム紙面＋明朝（典型1）や細罫線ブロードシート（典型3）に寄っていない
3. 通しレンダリング後、`ffprobe` で 60.00秒 / 1920x1080 / 音声なし / 100MB以下を確認
