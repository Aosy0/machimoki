PLATEAUの3D都市モデルを3Dプリントする手順

国土交通省PLATEAUの3D都市モデルは、そのままでも形は取り出せますが、 3Dプリンターで失敗せずに印刷するには「範囲の選び方」「地形の扱い」「スライサー設定」の3点が効きます。 ここでは、Machimoki を使う前提で、迷いやすいポイントを順に整理します。

1. 準備するもの

  • PCのブラウザ: Chrome または Edge の最新版を推奨します。WebAssembly と WebGL を使うため、古いブラウザでは動作しない場合があります。
  • メモリ: 広い範囲を選ぶとメモリ使用量が増えます。8GB以上を推奨します。
  • 3Dプリンターとスライサー: Bambu Studio、PrusaSlicer、OrcaSlicer、Cura など、3MF か STL を読み込めるものであれば何でも構いません。
  • フィラメント: 地形の起伏を表現するなら PLA が扱いやすく、細部の刻印も出やすいです。

インストール作業はありません。ブラウザで Machimoki を開けばすぐに始められます。

2. 範囲の決め方

最初に決めるのは「どの範囲を、どのくらいの大きさで印刷するか」です。 範囲を広げるほど情報量は増えますが、印刷サイズが大きくなり、造形時間と失敗率も上がります。

ベッドサイズから逆算する

一般的な家庭用プリンターのベッドは 180〜256mm 四方です。 余白を考えると、一辺 150〜200mm に収まる範囲から始めるのが無難です。 範囲選択時に表示される実寸（m）と模型サイズ（mm）を見ながら、 縮尺がおよそ 1/5,000〜1/10,000 になるように調整すると、街並みが読み取れる大きさになります。

地形の起伏を見る

坂や川沿い、埋め立て地など起伏のある場所は、模型としての見栄えが大きく変わります。 平坦な市街地を選ぶと「板にビルが並んだだけ」に見えやすいので、 高低差のある地形を含めると満足度が上がります。

対応範囲を確認する

PLATEAUの3D都市モデルは全国すべての地域に整備されているわけではありません。 地図上にカバレッジを重ねて表示できるので、選択前に目的の地域が含まれているか確認してください。 建物が表示されない場合は、その範囲のデータが未整備である可能性が高いです。

3. 設定の決め方

範囲を選んだら、右側のパネルで仕上がりを調整します。よく使う設定と、その選び方の目安です。

地形の厚み
地形モデルは面データなので、そのままでは薄いシートになります。 厚みを持たせると自立し、底面を平らにできます。印刷サイズ 200mm 程度なら 2〜4mm が目安です。 薄すぎると反り、厚すぎるとフィラメントと時間を消費します。
底面をフラット化
地形の凸凹を底面側で切り落とし、平らな面を作ります。 ベッドへの密着が安定し、反りを抑えられます。机に置いて飾る用途なら実質必須です。
実際の標高を反映する
オンにすると、範囲内の標高差をそのまま模型の高さに反映します。 山間部や海沿いでは差が出ますが、起伏が大きすぎて縦に伸びる場合は、 厚みや範囲を調整するか、オフにして平坦な模型にすると安定します。
LOD（詳細度）
LOD1 は建物を直方体で表す簡略モデル、LOD2 は屋根形状などを含む詳細モデルです。 広い範囲を小さく印刷するなら LOD1 で十分見栄えがします。狭い範囲を大きく印刷するなら LOD2 が向いています。
刻印
地名や座標、縮尺、出典などを底面や側面に彫り込めます。 FDMプリンターの 0.4mm ノズルでは、線幅が細すぎると潰れます。 Machimoki は最小サイズを考慮して自動で調整しますが、文字数を減らすとより確実です。
中空シェル・土台と建物の分割
底面を開口した中空構造にすると、LEDを仕込んだりフィラメントを節約できます。 土台と建物を2パーツに分けると、屋根を上に向けて印刷できるためサポート材を減らせます。

4. 書き出しとスライサー設定

設定が決まったら「3MF（推奨）」または「STL」でダウンロードします。 3MF は単位がmmで保持されるため、スライサー側で倍率を指定する必要がなく、複数パーツもまとめて扱えます。

主なスライサーでの開き方

  • Bambu Studio / OrcaSlicer: 「ファイル → インポート」から3MFを選択。パーツ分割されている場合はそのまま配置されます。
  • PrusaSlicer: 3MFをドラッグ＆ドロップ。単位はmmとして読み込まれます。
  • Cura: 「ファイル → 開く」からSTLを選択。単位がインチになっている場合は設定でmmに変更してください。

印刷設定の目安（0.4mmノズル・PLA）

街の模型を印刷するときの出発点。実際は造形物の大きさに合わせて調整してください
項目目安
レイヤー高さ0.16〜0.2mm（刻印をくっきり出したいなら0.12〜0.16mm）
壁の数2〜3
インフィル10〜15%（強度より表面のきれいさを優先）
サポート基本的に不要。分割した建物を寝かせる場合のみツリーサポートを検討
ビルドプレート密着ブリム（5mm程度）を付けると反りを抑えやすい

模型は底面が平らなので、そのまま置けば安定します。 細い塔や張り出した屋根がある場合は、分割出力を使って向きを変えるのが確実です。

5. つまずきやすい点と対処

建物が表示されない
選択した範囲のPLATEAUデータが未整備の可能性があります。 カバレッジ表示で対応範囲を確認し、別の地域を選んでみてください。
動作が重い・固まる
範囲が広すぎるか、LOD2で建物が多いエリアを選んでいます。 範囲を狭めるかLOD1に切り替えてください。生成はブラウザ内で行うため、他のタブを閉じると安定します。
切片が薄くて反る
地形の厚みを増やし、底面をフラット化してください。印刷時はブリムを付け、1層目をゆっくり印刷すると改善します。
刻印の文字が潰れる
文字を大きくするか、文字数を減らしてください。0.4mmノズルでは線幅0.4mm未満の溝は埋まりやすいです。 0.2mmノズルを使うと細かい文字も出ますが、印刷時間は延びます。
スライサーで「非多様体」と警告が出る
通常はMachimoki側で結合済みのため出ません。STLで読み込んだ場合に警告が出るなら、3MFで再出力してみてください。
サイズが想定と違う
STLには単位情報がないため、スライサーがインチとして解釈している可能性があります。 3MFを使うか、スライサーの単位設定をmmに変更してください。

6. Blenderなどで自分で作る場合との違い

PLATEAUのデータはCityGMLやOBJとしても配布されているため、Blenderなどの 3Dソフトで自分でSTLに変換することもできます。おおむね次の工程が必要です。

  1. データを探してダウンロードする

    対象の市町村のCityGML / OBJを配布ページから取得します。建物だけでも数百MB〜数GBになります。

  2. 建物を結合して隙間を埋める

    建物は1棟ごとの別メッシュで、地面との間に隙間があります。結合と穴埋めを手作業で行います。

  3. 土台を作ってスケールを調整する

    地形を平板化して底面を作り、mからmmへ縮小します。ノズル幅に対して薄い壁が残らないか確認します。

  4. STL / 3MF で書き出す

    エクスポート後、スライサーで水密性（非多様体エッジ）の警告が出ないか確認します。

Machimokiはこの工程をブラウザ内で自動化します。範囲選択から書き出しまで何度でも試せます。 一方、道路・鉄道・植生まで含めた模型を作る場合は、自作や有料の作成サービスが向いています。

7. 用語ミニ辞典

PLATEAU（プラトー）
国土交通省が主導する3D都市モデル整備・オープンデータ化プロジェクト。全国の都市の建物・地形などが公開されています。
3D Tiles
大量の3Dデータを段階的に読み込むための配信形式。表示範囲に応じて必要な分だけ取得します。
LOD
Level of Detail の略。LOD1は直方体の簡略モデル、LOD2は屋根形状などを含む詳細モデルです。
水密（ウォータータイト）
メッシュに穴や隙間がなく、中身が詰まった状態。スライサーが「中身のある物体」として正しく扱えます。
3MF / STL
3Dプリント用のファイル形式。3MFは単位・色・複数パーツを保持でき、STLは形状のみのシンプルな形式です。
スライサー
3Dモデルをプリンターが動ける指示（G-code）に変換するソフト。Bambu Studio、PrusaSlicer、Cura などがあります。

実際に作ってみる

ここまでの設定は、すべてブラウザ上で試せます。範囲を変えて何度でも生成できるので、 まずは小さめの範囲で1つ印刷し、成功したら範囲を広げていくのがおすすめです。
